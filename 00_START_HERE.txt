ШАГИ ДЛЯ ПУША В GITHUB:

1️⃣ СОЗДАТЬ РЕПО НА GITHUB
   Перейти: https://github.com/new
   Название: bot_klima
   License: MIT (опционально)
   ⚠️ НЕ инициализировать README, .gitignore, LICENSE

2️⃣ НАСТРОИТЬ ЛОКАЛЬНЫЙ РЕПО
   git remote add origin https://github.com/your-username/bot_klima.git
   git branch -M main

3️⃣ ПУШИТЬ КОД
   git push -u origin main
   git push -u origin develop

4️⃣ ЗАЩИТИТЬ MAIN ВЕТКУ
   GitHub → Settings → Branches → Branch protection rules
   ✓ Require pull request reviews before merging
   ✓ Require status checks to pass

5️⃣ ДОБАВИТЬ TOPICS
   GitHub → About (⚙️) → Topics
   ✓ telegram, bot, aiogram, python, sqlalchemy, postgresql

6️⃣ ОТКРЫТЬ PR
   git checkout develop
   git push origin develop
   GitHub → Create Pull Request (develop → main)

7️⃣ ПОСЛЕ MERGE В MAIN
   git tag v0.1.0
   git push origin v0.1.0
   GitHub → Releases → Create release from tag
