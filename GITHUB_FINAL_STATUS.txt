## 🚀 Команды для пуша

### Вариант 1: Быстро (если уже есть remote)
```bash
cd c:\Users\macen\Documents\bot_klima

# Проверить статус
git status

# Убедиться что .env не в staging
git diff --cached --name-only | grep -i "\.env"  # Не должно быть результата

# Пушить
git push origin develop
```

### Вариант 2: С нуля (создание репо)
```bash
# На GitHub: https://github.com/new
# Название: bot_klima
# НЕ инициализировать файлы

# Локально:
cd c:\Users\macen\Documents\bot_klima

git remote add origin https://github.com/your-username/bot_klima.git
git branch -M main

git push -u origin main
git push -u origin develop

# На GitHub Settings → Branches:
# Требовать pull requests перед merge
```

### Вариант 3: С чеклистом (рекомендуется)
```bash
# Запустить pre-push checks
bash scripts/prepush.sh

# Если всё ок:
git push origin develop

# Открыть PR на GitHub
```
